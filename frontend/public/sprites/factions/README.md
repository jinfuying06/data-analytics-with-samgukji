# 위·촉·오 세력 깃발

삼국지 데이터 원정대 UI에서 사용하는 독창적인 저해상도 픽셀 군기다.

| 세력 | 표기 | 주조색 | 형태 |
| --- | --- | --- | --- |
| 위 | 위 | 적색·진홍·검정 | 각진 기하 테두리와 깊은 제비꼬리 |
| 촉 | 촉 | 비취·녹색·갈색 | 둥근 테두리와 매듭 장식 |
| 오 | 오 | 남청·청색·청록 | 물결 테두리와 비대칭 수군 깃끝 |

각 세력은 기본 PNG, `1행 × 4프레임` 스트립, 무한 반복 GIF를 가진다.

- 프레임: 420 × 250 px
- 프레임 수: 4
- 속도: 1.25 FPS(프레임당 0.8초, 한 바퀴 3.2초)
- 배경: 실제 투명 알파
- 글꼴: `굴림체 Bold`를 저해상도 단색으로 렌더링하고 1논리 픽셀 외곽선을 더한 뒤 3배 정수 확대
- CSS 권장값: `image-rendering: pixelated`

이미지 생성 도구에는 글자 없는 군기와 네 단계의 미세한 천 움직임만 요청했다. `위`, `촉`, `오` 표기는 생성 결과에 의존하지 않고 후처리로 정확히 합성했다. 현재 manifest는 작은 표시 크기에서도 읽히도록 글자를 키운 v2를 사용하며, 최초의 얇은 v1도 비교용으로 보존한다.
