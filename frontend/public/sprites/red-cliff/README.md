# 적벽대전 캐릭터 스프라이트

인물별 외형은 `docs/RED_CLIFF_CHARACTER_BIBLE.md`와 `config/sprite-agent/red-cliff-character-bible.json`을 따른다. 위는 적색, 촉은 녹색, 오는 청색 계열이다. 세력색은 전체 면적의 45~55%를 차지하며 머리·상체·허리 아래 중 최소 두 구역에 반복한다. 현재 주유·조조 이미지는 재설계 대상 시제품이다.

## 파일 규칙

```text
<character-id>-base.png
<character-id>-idle.gif
<character-id>-attack.gif
<character-id>-hit.gif
<character-id>-defeat.gif
<character-id>-victory.gif
<character-id>-sheet-v<version>.png
manifest.json
```

한 캐릭터는 기본 PNG 1장과 4프레임 GIF 5개를 가진다. `idle.gif`는 화면에서 계속 재생하고, 나머지 애니메이션은 전투 상태가 변경될 때 재생한다.

## 표시 권장값

- 애니메이션 프레임: 420 × 250 px 공통 투명 캔버스
- 웹 표시 크기: 약 210 × 125 px 또는 그 정수배
- CSS: `image-rendering: pixelated`
- 배경: 투명 알파
- 기준 방향: 화면 오른쪽

## 적벽대전 1차 제작 명단

1. 주유: 청색 갑옷, 짧은 청록 망토, 직검
2. 조조: 진홍·검정 지휘관 복식, 짧은 허리천, 지휘검
3. 제갈량: 흰색·청색 도포, 학창의, 깃털 부채
4. 손권: 오나라 군주관, 청색·금색 예복, 패검
5. 유비: 녹색·갈색 장포, 쌍검
6. 황개: 노장 실루엣, 중갑, 군용도

각 인물은 같은 신체 비율과 프레임 규격을 유지하되 색, 머리 장식, 망토, 무기 실루엣으로 구분한다.

## 모션 분리 규칙

- 최종 제작은 전체 캐릭터 시트가 아니라 모션별 `1행 × 4프레임` 스트립을 사용한다.
- 프레임을 동일 폭으로 기계적으로 나누지 않고, 각 포즈 사이의 실제 투명 구간을 경계로 사용한다.
- 검 궤적과 피격 효과까지 포함한 뒤 420 × 250 공통 캔버스 중앙에 배치한다.
- GIF 생성 전 모든 프레임의 상하좌우 경계와 다른 포즈의 잔여 픽셀을 검사한다.
