# 게임 데모 대화창 초상화 제작 지시서

`prototype/game-demo` 전용 자산이다. 프로젝트 본 스프라이트 파이프라인(`frontend/public/sprites/red-cliff`, 로스터, 매니페스트)과 분리한다.

## 이번 실행에서 할 일

인물 **한 명**의 대화창용 상반신 초상화 PNG 한 장을 만든다. 대상 인물 id는 실행 명령에서 받는다.

- 저장: `prototype/game-demo/assets/portraits/<id>.png`
- 기록: `prototype/game-demo/assets/portraits/<id>.json` (아래 형식)
- 그 밖의 파일은 만들거나 고치지 않는다. 특히 `config/sprite-agent/*`, `frontend/public/sprites/*`, `docs/*`는 건드리지 않는다.
- 이미지 생성 도구를 쓸 수 없으면 대체 그림(직접 그린 도형, 다른 인물 복사 등)을 만들지 말고 중단 사유만 보고한다.

## 화풍 기준: 기록관 그림

기준 이미지: `prototype/game-demo/assets/ref/archivist-ref.png` (바깥 흰 테두리와 그림자는 슬라이드 장식이므로 무시)

이 그림의 화풍을 따른다.

- 굵은 도트: 그림 전체가 가로 약 64~80 논리 픽셀 격자로 보이고, 최근접 보간으로 확대된 느낌
- 1논리 픽셀 짙은 외곽선, 평면 채색에 2~3단계 명암, 그라데이션·흐림·반투명 금지
- 큰 머리의 귀여운 SD 비율, 가슴 위 상반신 구도, 얼굴은 정면 또는 오른쪽 3/4
- 손에 대표 소품 하나를 들어 인물을 알아보게 함 (기록관의 돋보기처럼)
- 배경은 단색 짙은 남색 `#1B2530` 정사각형. 무늬·체크무늬·글자·로고 금지
- 피부 포함 12~20색

기록관 자체와 구별되어야 한다. 기록관의 흰 관·흰 깃털부채·돋보기 조합을 다른 인물에 그대로 쓰지 않는다.

## 인물별 내용: 디자인 바이블

`config/sprite-agent/red-cliff-character-bible.json`에서 같은 id 항목을 읽고 따른다.

- `colorPlan`, `silhouette`, `signature`, `face`, `avoid`
- 세력색은 `factions`의 팔레트를 사용하고 머리·상체 두 구역 이상에서 반복한다. 위=적색·진홍, 오=남청·청색, 촉=녹색, 기타=독자색
- 바이블의 '초기 콘솔풍 전신·48×64' 규격은 전신 스프라이트용이므로, 이 초상화에서는 위 화풍 기준이 우선한다
- 특정 삼국지 게임·애니메이션의 디자인을 복제하지 않는다

## 출력 규격과 검수

- 512×512 PNG, 배경 `#1B2530` 단색(모서리 4곳 픽셀이 이 색과 거의 같아야 함)
- 머리가 화면 높이의 45~60%, 머리 꼭대기와 소품이 잘리지 않음
- 96×96으로 줄였을 때 세력색과 대표 소품을 알아볼 수 있음
- 검수는 직접 이미지를 열어 확인하고, 모서리 색은 스크립트로 확인한다

`<id>.json` 형식:

```json
{ "id": "zhuge-liang", "nameKo": "제갈량", "faction": "촉", "file": "zhuge-liang.png",
  "size": [512, 512], "cornerColor": "#1b2530", "status": "pass | fail",
  "notes": "세력색 배치, 소품, 바이블과 다른 점" }
```

최종 답변은 한국어로 status, 저장 경로, 검수 결과, 남은 문제를 짧게 보고한다.
