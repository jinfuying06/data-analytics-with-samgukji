# 삼국지로 배우는 데이터분석 — 적벽대전 편 (프로토타입)

> 이 문서의 단계 설명은 초기 설계 기록입니다. 현재 여섯 단계와 선택형 정사 확장의 구성은 [WHATIF_LEARNING_JOURNEY.md](WHATIF_LEARNING_JOURNEY.md)를 기준으로 합니다.

`prototype/red-cliff-lab/index.html` 하나로 동작하는 학습 웹앱. 서버 없이 브라우저에서 바로 열린다.
데이터는 모두 공개 seed DB(`data/seed/red_cliff.db`)에서 계산했다.

## 출발점

"삼국지로도 데이터분석을 할 수 있을까?", 그리고 "만약 그 사람이 다른 편이었다면?"을 데이터로 계산해 볼 수 있을까.
블로그 글 「데이터로 덕질하는 삼국지 – 적벽대전」의 흐름
(진영 전력 비교 → 평균의 함정 → 상황에 맞는 특화 지표와 가중치 → What-if)을 seed DB만으로 재구성했다.
게임 능력치 대신 텍스트에서 직접 지표를 만든다.

## 여섯 단계

| 단계 | 질문 | 배우는 것 | 쓰는 데이터 |
|---|---|---|---|
| 1 | 누가 이 싸움에 나왔을까? | 데이터 만들기: 명단 규칙(최소 등장 회, 사망자 제외) | 연의 등장 기록 186줄 |
| 2 | 위나라가 더 강했을까? | 평균의 함정: 합계·평균·중앙값, 분포, 극단값 | 인물별 등장 문단 수 |
| 3 | 승패를 가른 건 무엇일까? | 지표 설계와 가중치: 수전·화공·계책 | 연의 문단 속 키워드 |
| 4 | 점수 규칙을 바꿔도 결론이 같을까? | 민감도 분석: 가중치 215조합 | 3단계 지표 (연의/정사, 합계/1인당) |
| 5 | 이 지표를 믿어도 될까? | 프록시의 한계와 출처 비교 | 근거 문단, 정사 본문·주석 |
| 6 | 만약 그 사람이 다른 편이었다면? | 시뮬레이션: 인물 이동·제외, 렌즈, 바람 가정 | 1~5의 결과 + 동시 등장 1,340쌍 |

1단계 명단과 3단계 가중치는 이후 단계의 계산에 그대로 이어진다.

## 지표 정의

- **존재감**: 이름이 들어간 연의 문단 수 (한 문단에 여러 번 나와도 1).
- **수전 / 화공 / 계책**: 이름이 들어간 문단(정사는 문장)에 `船·舟·水軍·艦` / `火·燒·焚` / `計·謀·策` 중 하나가 함께 나온 수.
- **바람(風)**: 사람의 능력이 아닌 환경 조건으로 보고 전력 점수에서 뺀다. 6단계에서 '날씨'(기본) 또는 '제갈량의 능력(연의 관점)' 중 하나로 가정한다.
- **진영**: 정사가 인물을 위·촉·오로 나눠 실은 분류를 따른다.
- **정사 층**: 본문과 배송지 주석(〈 〉 안)을 나눠 센다. 연의(문단)와 정사(문장)는 단위가 달라 비중(%)으로만 비교한다.
- **연합 우세 지수** (6단계): 연합 점수 ÷ (연합 + 위) × 100, 바람 가정에 따라 ±보너스.

## 기본 명단 기준(2회 이상, 사망자 제외)에서 나오는 값

- 명단: 위 15 · 오 20 · 촉 7명
- 1인당 평균 존재감: 촉 22.9 · 오 15.6 · 위 10.2 / 촉 문단의 56%가 제갈량
- 연의 전력 점수(수전 3·화공 3·계책 2): 연합 1,255 vs 위 467
- 민감도: 연의·합계 215/215, 정사 본문·1인당 203/215
- 조조의 화공 18은 불에 당한 장면의 동시 출현
- 촉의 점수 비중: 연의 20% → 정사 본문 14%
- 제갈량→위: 연의 83→72, 정사 81→77, 정사 본문에서 바람을 제갈량의 능력으로 보면 56, 연의에서 바람을 제갈량의 능력으로 보면 52

## 한계

- 키워드 동시 출현은 능력이 아니라 '함께 나온 글자'다. 가해·피해를 구분하지 못한다(5단계에서 다룸).
- 근거 문단은 seed DB에 번역이 있는 문단 안에서만 보여 준다.
- 진영을 옮겨도 이야기 속 관계(동시 등장)는 그대로라서, 6단계 결과는 '이 가정이라면 이렇다'는 추정이다.

## 빌드

```sh
python scripts/build_red_cliff_lab_data.py   # seed DB → src/30-data.js
sh prototype/red-cliff-lab/build.sh          # src/* → index.html
```

`src/`의 파일 순서대로 이어 붙여 단일 HTML을 만든다.

| 파일 | 내용 |
|---|---|
| `00-head.html` | 제목, 폰트, 기본 스타일, 아이콘 |
| `10-styles-course.html` / `11-styles-stages.html` / `12-styles-journey.html` | 단계 화면 스타일 |
| `13-styles-simple.html` | 단순화한 단계 화면 스타일 |
| `15-styles-lab.html` / `90-whatif-lab.js` | What-if 실험실: 질문 9개, 직접 만들기, 답할 수 있는 질문 고르기 |
| `14-styles-cinema.html` / `85-cinema.js` | 공통 시네마틱 연출: 모든 화면(홈 그림 포함)이 같은 '강 위의 밤' 색과 장면(안개·불티)을 쓰고, 단계가 진행될수록 불길(`--heat`)이 커진다. 화면 전환 컷, 레터박스, 결과 공개 효과를 통일. 의미 없는 장식선은 쓰지 않는다. 움직임 줄이기 설정을 따른다 |
| `20-markup.html` | 앱 골격, 오프닝, 탭바 |
| `30-data.js` | 생성 데이터 (직접 수정하지 않음) |
| `40-app.js` | 여섯 단계 화면과 계산 |
| `70-learning-journey.js` | 홈 질문·예상, 단계 연결 |
| `80-simplify.js` | 단계마다 '행동 → 결과 → 개념 이름' 화면 (계산은 40-app 그대로) |
| `50-fx.js` / `60-intro.js` | 씬 배경 효과, 다섯 장면 오프닝 |

진행 상황은 브라우저 `localStorage`(`redcliff-v8`)에만 저장된다.
