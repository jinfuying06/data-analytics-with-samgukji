# 삼국지 데이터 원정대 PRD

문서 상태: 초안 v0.1  
작성 목적: 스토리라인, 시뮬레이션, 학습실, 도감의 역할을 분리하고 이후 구현 기준을 고정한다.

## 1. 제품 한 줄 정의

**삼국지 원문 데이터를 가볍게 게임처럼 탐험하고, 역사적 조건을 바꿔 What-if를 실행하며 데이터 분석을 배우는 픽셀형 역사 시뮬레이션 플랫폼**

## 2. 제품이 해결하려는 문제

삼국지 원문에는 인물·사건·관계 정보가 풍부하지만, 일반 사용자가 이를 데이터로 분석하거나 가상 상황을 실험하기는 어렵다.

이 제품은 다음 흐름을 제공한다.

```text
스토리 이해 → 인물·근거 확인 → 조건 변경 → 결과 비교 → 데이터로 해석
```

첫 번째 대상 스토리라인은 **적벽대전**이며, 연의 제43회~제50회를 기준으로 한다.

## 3. 대상 사용자

### 1차 사용자

- 삼국지에 관심이 있지만 분석 도구에는 익숙하지 않은 사람
- 데이터 분석을 재미있는 주제로 연습하려는 학습자
- 원문 근거를 확인하면서 인물과 사건을 비교하고 싶은 사용자

### 2차 사용자

- 역사·문헌 데이터를 탐색하는 연구자
- 규칙 기반 시뮬레이션을 직접 설계해보고 싶은 개발자

## 4. 제품 원칙

1. **쉽게 시작한다**: 첫 화면에서 데이터베이스나 복잡한 차트보다 사건과 선택지를 먼저 보여준다.
2. **게임처럼 탐험한다**: 월드맵, 스테이지, 장수 카드, 잠금 해제 구조를 사용한다.
3. **근거를 숨기지 않는다**: 모든 점수·결과는 원문 근거와 계산 규칙으로 추적 가능해야 한다.
4. **사실과 가정을 구분한다**: 역사 기록, 데이터 기반 계산, 사용자의 가정을 서로 다른 상태로 표시한다.
5. **분석을 결과 뒤에 연결한다**: 시뮬레이션을 실행한 뒤 어떤 변수가 결과에 영향을 주었는지 학습하게 한다.

## 5. 정보 구조

```text
스토리라인
├─ 적벽대전 브리핑
├─ 회차 진행도
└─ 사건·인물 탐색

시뮬레이션
├─ 사건 선택
├─ 세력·장수 선택
├─ 조건 변경
├─ 실행
└─ 결과·민감도 분석

학습실
├─ 단계별 분석 과제
├─ 정사·연의 비교
├─ 차트·지표 실습
└─ 시뮬레이션 결과 해석

도감
├─ 장수
├─ 사건
├─ 관계망
└─ 원문·번역·출처
```

## 6. 핵심 사용자 흐름

### A. 스토리라인 탐험

1. 사용자가 적벽대전을 선택한다.
2. 제43회~제50회의 흐름을 한국어 회목으로 확인한다.
3. 회차별 주요 인물을 확인한다.
4. 장수 카드를 눌러 정사·연의 기록과 근거를 본다.
5. `시뮬레이션으로 이동`을 선택한다.

### B. What-if 시뮬레이션

1. 사건으로 적벽대전을 선택한다.
2. 기본 역사 조건을 확인한다.
3. 세력과 장수를 선택하거나 교체한다.
4. 화공, 동남풍, 수전 대비, 동맹 등 조건을 변경한다.
5. 시뮬레이션을 실행한다.
6. 기준 역사와 가상 결과를 비교한다.
7. 결과에 가장 큰 영향을 준 변수를 확인한다.
8. 학습실에서 분석 문제를 이어서 푼다.

### C. 데이터 분석 학습

1. 사용자가 분석 과제를 선택한다.
2. 사용할 데이터와 질문을 확인한다.
3. 필터·집계·차트·간단한 모델을 단계별로 실행한다.
4. 결과를 해석한다.
5. 실제 역사 기록과 분석 결과의 차이를 확인한다.

## 7. 화면 요구사항

### 7.1 스토리라인 탭

목적: “무슨 사건이 있었는가?”를 게임처럼 이해한다.

필수 요소:

- 스토리라인 제목과 한 줄 설명
- 사건의 시작·종료 회차
- 한국어 회차 타임라인
- 회차별 주요 인물
- 실제 역사 결과 요약
- `시뮬레이션 시작` 버튼

스토리라인 화면은 시뮬레이션 설정 화면이 아니다. 조건 변경 컨트롤은 이 화면에 두지 않는다.

### 7.2 시뮬레이션 탭

목적: “조건을 바꾸면 결과가 어떻게 달라지는가?”를 실험한다.

필수 요소:

- 사건 선택
- 기준 시나리오와 사용자 시나리오 구분
- 세력·장수 선택
- 조건 변경 컨트롤
- 실행 버튼
- 기준 결과와 가상 결과 비교
- 결과에 영향을 준 변수
- 재실행·조건 하나만 바꾸기

초기 적벽대전 조건 후보:

- 화공 대비 여부
- 동남풍 발생 여부
- 조조군 수전 경험
- 손권·유비 동맹 유지 여부
- 황개의 거짓 항복 성공 여부

단, 위 조건들은 현재 데이터에서 자동으로 산출된 사실이 아니라 초기 시뮬레이션 가정이다. 구현 전 각 조건의 근거와 계산 규칙을 확정해야 한다.

### 7.3 학습실 탭

목적: “결과를 데이터 분석 관점에서 어떻게 이해하는가?”를 배운다.

필수 요소:

- 질문 중심의 짧은 과제
- 사용 데이터와 변수 설명
- 단계별 힌트
- 표·차트 결과
- 결과 해석 입력 또는 선택
- 정답보다 분석 과정과 근거에 대한 피드백

초기 과제 후보:

- 적벽대전 8회차의 등장 인물 수 비교
- 주요 인물별 등장 회차 수 비교
- 정사·연의 등장 여부 비교
- 공동등장 관계망에서 중심 인물 찾기
- 시뮬레이션 결과에 가장 민감한 변수 찾기

### 7.4 도감 탭

목적: 분석에 사용된 데이터와 원문 근거를 확인한다.

필수 요소:

- 장수 검색
- 정사 기록
- 연의 등장 회차
- 한국어 번역이 있으면 번역문 우선 표시
- 원문·출처 URL
- 향후 점수의 근거 문장
- 관계망 연결

## 10. 중요한 불변 조건

- 원문과 출처 URL은 삭제하지 않는다.
- 한국어 표시명과 원문 회목은 별도 필드로 보존한다.
- 점수는 근거 문장과 계산 규칙 없이 확정하지 않는다.
- 사료에 없는 가정은 `사용자 가정`으로 표시한다.
- 시뮬레이션 결과는 역사적 사실이 아니라 모델의 결과로 표시한다.
- 같은 입력·같은 규칙으로 재실행하면 같은 결과를 재현할 수 있어야 한다.
- 근거가 부족한 인물은 낮은 점수가 아니라 `근거 부족` 상태로 구분할 수 있어야 한다.

## 11. 현재 구현과의 차이

현재 프로젝트는 다음 기반을 갖고 있다.

- 원문 수집·정제 파이프라인
- 인물별 정사·연의 데이터
- SQLite·FastAPI 조회 API
- Next.js 인물·관계망 화면
- 적벽대전 제43회~제50회 스토리라인 API

아직 없는 핵심 기능:

- 사건·전투 데이터 모델
- 정식 점수 정의와 산출 규칙
- 시뮬레이션 실행 엔진
- 학습 과제와 분석 실행 환경

따라서 현재 단계의 목표는 “완성된 역사 시뮬레이터”가 아니라, **적벽대전을 대상으로 각 기능 탭의 역할을 분리하고 데이터·근거 구조를 검증하는 프로토타입**이다.

## 12. 성공 기준

초기 성공은 사용자가 다음을 10분 안에 수행할 수 있는지로 판단한다.

1. 적벽대전 스토리라인의 흐름을 이해한다.
2. 주유·제갈량·조조·손권 중 한 명의 근거 기록을 확인한다.
3. 최소 한 가지 조건을 바꾼 시나리오를 만든다.
4. 기준 결과와 가상 결과의 차이를 확인한다.
5. 결과에 영향을 준 변수를 데이터 관점에서 설명한다.

## 14. 미결정 사항

- 초기 사용자를 프로젝트 소유자 중심으로 할지, 일반 공개 사용자까지 포함할지
- 장수 점수 항목을 무엇으로 할지
- 시뮬레이션을 결정론으로 할지 확률형으로 할지
- 승패 외에 어떤 결과 지표를 사용할지
- 분석 학습을 UI 기반으로 할지, Python/SQL 실행 기반으로 할지
- 한국어 회차 제목을 자체 번역으로 유지할지, 별도 검수할지
- 적벽대전 이후 다음 스토리라인을 어떤 순서로 추가할지

## 15. 학습실 카드 커리큘럼

학습실은 데이터 분석 경험이 없는 사용자가 적벽대전 데이터를 보면서 분석의 기본 순서를 익히는 별도 탭이다. 한 화면에 복잡한 대시보드를 먼저 보여주지 않고, 카드 한 장을 읽고 다음 카드로 이동하는 방식으로 구성한다.

```text
질문 만들기 → 데이터 한 줄 읽기 → 범위 필터링 → 인물별 집계
→ 비교 시 주의점 확인 → 결과를 문장으로 설명
```

### 카드 1. 질문을 한 문장으로 만들기

- 예시 질문: “적벽대전에서 가장 많이 등장한 인물은 누구일까?”
- 대상, 분석 범위, 비교 기준을 질문에 포함한다.

### 카드 2. 데이터 한 줄을 읽어보기

- 회차, 인물, 기록 필드를 예시 표로 보여준다.
- 한 줄이 무엇을 의미하는지 먼저 확인한다.

### 카드 3. 필요한 범위만 골라내기

- 연의 제43회~제50회, 인물 등장 기록 등 현재 질문에 필요한 필터를 선택한다.
- 적벽대전 범위는 8회차, 63명으로 표시한다.

### 카드 4. 인물별로 모아 세기

- 인물별 등장 회차 수를 막대 형태로 보여준다.
- 집계 결과와 원자료를 구분한다.

### 카드 5. 비교할 때 조심하기

- “가장 많이 등장했다”와 “가장 유능했다”를 구분한다.
- 등장 빈도만으로 능력·공헌·승패를 결론 내리지 않도록 한다.

### 카드 6. 결과를 문장으로 설명하기

- 숫자, 기준, 해석의 한계를 포함한 결과 문장 템플릿을 제공한다.
- 학습 완료 후 시뮬레이션 탭으로 이동시킨다.

학습실의 1차 목표는 정답률보다 **질문을 만들고, 데이터의 범위를 제한하고, 집계 결과를 근거와 함께 설명하는 습관**을 만드는 것이다.
