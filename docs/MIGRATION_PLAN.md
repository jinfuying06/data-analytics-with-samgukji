## 진행 원칙

1. 기존 화면과 배포 주소는 갈아타는 날까지 그대로 둔다.
2. 새 게임은 `/game/` 하위 주소로 함께 배포해 나란히 비교한다.
3. 데이터와 계산은 한 벌만 쓴다. 새 계산이 기존 결과와 같은지는 테스트로 확인한다.
4. 아래 표에서 '옮김'인 항목이 모두 새 게임에서 돌아가고 사용자가 확인하면 메인 주소를 바꾼다. 기존 화면은 `/classic/`에 남긴다.
