# 어린이 중심 학습 흐름 개편

대상: 초등학교 6학년. 목표: “이야기를 같은 기준으로 정리하면 데이터로 비교할 수 있다”를 자기 말로 설명한다.

## 새 경험

- 홈: 삼국지 이야기가 어떻게 표가 되는지 바로 보여준다. 학습 목표·소요 시간·선행 지식 불필요를 안내한다.
- 예상: 조조·유비·제갈량의 짧은 소개를 읽고 예상한다. “아직 모르겠어요”도 동등하게 선택할 수 있다.
- 이름 찾기: 43–44회 편집 요약을 읽고 조조·제갈량·손권에게 직접 표시한다. 주유를 선택하거나 필요한 이름을 빠뜨리면 설명을 보여주며 완료 처리하지 않는다.
- 연습 표는 전체 회차의 모든 인물을 나타내지 않음을 명시한다.
- 실제 기록: 8개 회차의 공개 SQLite 기록 186건/63명을 사용한다. 서로 다른 회차 수를 세고, 전체 63명 결과를 표·막대그래프로 탐색한다.
- 해석: 등장한 이야기 수만으로 전투 실력·공헌도를 알 수 없음을 선택형 피드백으로 확인한다. 알맞은 해석을 고른 뒤 완료 화면으로 진행한다.
- 전이: 다른 책의 등장인물도 같은 방식으로 정리할 수 있다는 다음 질문을 제시한다.
- 전투: 기존 규칙과 국기 에셋은 유지하고 학습 완료 뒤의 별도 상상 실험으로 연결한다.

## 구현 원칙

기존 Next.js·FastAPI·SQLite·국기 에셋을 유지한다. seed DB는 변경하지 않는다. 배포본은 원본에서 추출한 실제 기록으로 집계한다. 실시간 API 미연결·추출 기준·모델 임의성은 선생님/보호자 안내와 근거 패널에서 확인할 수 있다. 어린이의 주요 활동에는 SQL 등 구현 용어를 제시하지 않는다.

피드백 기능은 기존 브라우저 메모를 이어 사용한다. 요소 선택, 검토 표시, JSON 내보내기를 제공한다. 서버 공유 기능은 없다.

## 검증 기록

- TypeScript 검사, 기존 36개 집계 범위·12개 모델 조합 검증.
- 연습 선택 16가지 조합 중 정답 1개 조합만 완료 가능함을 검증.
- 정적 프로덕션 빌드와 실제 화면/상호작용 검수 결과는 최종 작업 보고에 기록한다.

## 이번 검수 결과

- 정적 프로덕션 빌드 및 타입 검사 통과.
- `node tests/learning-flow.cjs`: 실제 React 컴포넌트의 상태 전환을 DOM 없는 하네스로 실행. 예상 선택, 연습 오답 수정, 실제 집계 결과(조조 8편), 표/그래프 전환, 미적용·잘못된 필터 처리, 해석 응답 완료 조건, 선택형 전투 진입 통과.
- 기존 집계·모델 검사와 연습 답 조합 검사 통과.
- 미리보기 supervisor의 mailbox가 없어 브라우저 시각·클릭·모바일 실기 검수 미완료. 상태 전환 자동 검사는 브라우저 검수를 대체하지 않는다.

## 화면 문구 기준

초등학생도 이해할 수 있는 짧고 쉬운 설명에 정중한 해요체를 사용한다. 질문은 “~할까요?”, 안내는 “~해 보세요”, 피드백은 “~하셨어요”처럼 작성한다. 학습자를 “너”라고 부르거나 반말로 지시하지 않는다. 예: “이야기를 표로 바꿔 볼까요?”, “첫 데이터 분석을 마치셨어요!”
