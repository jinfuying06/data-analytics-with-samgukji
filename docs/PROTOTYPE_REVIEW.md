## 구현

- Next.js 16.3.7 / React 기존 프레임워크를 유지한 정적 배포. FastAPI와 SQLite seed도 보존.
- 홈: 제43–50회 5단계 브리핑, 사건 선택, 인물·원문 근거 패널, 분석/실험 진입.
- 학습: 범위 선택 → 직접 집계 → 상위 12명 막대그래프 / 전체 순위표 / 원자료 → 해석 피드백.
- 실험: 거짓 항복·동남풍·화공 대비, 기준/변경 비교, 입력 미적용 안내, 기준값 복원.
- 모델: PRD v0.2의 순수 함수 v0.1. 실제 승률·피해율이 아닌 학습용 지수.
- 전투: 기존 위·오·촉 국기 에셋만 사용. 4개 판정의 전진/부분 후퇴/후퇴/대치. 건너뛰기·재생·동작 감소 지원.
- 근거 패널: 원문·소스 링크, SQL 집계 기준, 모델 수식 및 변경 가정. 중국어 원문, 번역 미제공.
- 디자인 피드백: 버튼 → 화면 요소 선택 → 의견 → 검토 상태. 현재 브라우저 localStorage 저장, JSON 내보내기 지원.

## 실제 연결과 한계

배포 환경은 정적 Next.js 산출물을 호스팅하며 Python/FastAPI 프로세스를 실행하지 않습니다. 따라서 공개 `data/seed/red_cliff.db`에서 읽기 전용으로 추출한 186건/63명 데이터로 브라우저 집계를 수행합니다. 하드코딩한 예시 숫자나 새 DB가 아닙니다. `frontend/lib/seed-snapshot.json`에 원본 SHA256과 소스 커밋을 기록했습니다.

로컬 기본 실행은 `/api/analytics/appearances`를 기존 FastAPI로 전달합니다. 연결 실패 시 오류를 표시하며 스냅샷으로 조용히 대체하지 않습니다. 배포본은 실시간 DB 변경을 반영하지 않으므로 seed 변경 후 다시 빌드해야 합니다.

피드백은 브라우저별 저장이며 계정·팀 간 공유, GitHub 이슈 전송, 실제 코드 변경 추적은 연결되지 않았습니다. 검토 완료 체크는 코드 수정 완료를 뜻하지 않습니다.

첫 비공개 배포 당시에는 기존 저장소/main에 쓰거나 PR을 생성하지 않았습니다. 이후 사용자 승인으로 아래 프로토타입 변경분을 GitHub main에 반영합니다. 원본 커밋 `1793bc0a6239f49320b9157e59611e3ff499fb01`을 별도 디렉터리로 복사해 작업하고 Sites의 별도 소스 저장소에 보존했습니다. 기존 인물 상세/관계망/스프라이트 탐색 경로는 보존하고 정적 배포용 seed 대체 경로를 추가했습니다.

## 실행

프로젝트 루트:

```sh
python -m venv .venv
.venv/bin/pip install -r backend/requirements.txt httpx
.venv/bin/uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

별도 터미널:

```sh
cd frontend
npm ci
npm run dev
```

정적 배포 빌드(루트):

```sh
npm run build
```

`dist/`에 출력합니다. `/proc`가 없는 제한된 호스트에서만 다음 빌드 호환 옵션이 필요합니다:

```sh
NODE_OPTIONS="--require $(pwd)/scripts/restricted-memory.cjs" npm run build
```

이 옵션은 정상 환경의 네이티브 메모리 측정을 그대로 사용하며, 해당 시스템 호출이 실패하는 호스트에서 빌드 중 메모리 진단만 V8 통계로 대체합니다.

## 검증

```sh
node tests/model-and-analytics.cjs
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
```

- 36개 유효 회차 범위: 브라우저 집계 함수 / API / SQLite SQL 결과 일치.
- 범위·limit 입력 오류 6종: 422 확인.
- 기존 스토리·인물 목록·인물 상세·관계망 API: 200 확인.
- 모델 기준 출력: 90 / 86 / 78 / 87.
- 12개 조건 조합: 결정론·0–100 범위·네 가지 결과 확인.
- DB SHA256 확인, 중복 행 distinct 처리 및 빈 결과 테스트.
- 지원되는 브라우저 제어 도구가 없어 시각·클릭·모바일 실기 검수는 미완료. 반응형 CSS와 키보드/네이티브 dialog 포커스 처리는 구현했지만 실기 검증과 구분합니다.
