# 적벽대전 캐릭터 한 명 제작

먼저 `AGENTS.md`, `docs/PIXEL_CHARACTER_AGENT.md`, `docs/RED_CLIFF_CHARACTER_BIBLE.md`, `config/sprite-agent/red-cliff-character-bible.json`, `frontend/public/sprites/red-cliff/README.md`, `config/sprite-agent/red-cliff-roster.json`을 전부 읽어라.

로스터에서 `needs-redesign` 상태인 최상단 캐릭터를 우선 선택하고, 없으면 `queued` 상태인 최상단 캐릭터 한 명만 선택해 완성하라. 이미 `complete`인 캐릭터는 다시 만들거나 덮어쓰지 마라.

반드시 수행할 작업:

1. 대상 인물의 세력, 역할, 대표 무기, 실루엣, 주조색을 로스터와 디자인 바이블에서 확인한다. 둘이 다르면 디자인 바이블을 우선하고 차이를 보고한다.
2. 사용자 예시 이미지는 낮은 픽셀 밀도·큰 머리·짧은 팔다리·귀여운 인상의 참고용으로만 사용하고 디자인을 복제하지 않는다. 기존 주유·조조 시제품의 세련된 고해상도 표현은 따르지 않는다. 바이블의 `colorPlan`에 따라 독자적인 기본 PNG를 생성한다.
3. 승인 가능한 기본 이미지를 기준으로 대기·공격·피격·패배·승리 모션을 각각 `1행 × 4프레임` 스트립으로 생성한다.
4. 실제 투명 알파를 검사한다. 체크무늬 그림은 실패다.
5. 실제 투명 구간을 기준으로 프레임을 분리하고 420 × 250 공통 캔버스에 배치한다.
6. `docs/PIXEL_CHARACTER_AGENT.md`의 FPS로 GIF를 만든다.
7. 20개 프레임 검수 이미지와 자동 검사 결과로 잘림·혼입·알파를 확인한다. 기본 이미지를 96px 높이로 축소했을 때 세력색이 먼저 읽히는지도 검사한다.
8. 캐릭터 폴더, manifest, `/sprites` 미리보기를 갱신한다.
9. 모든 검사를 통과한 경우에만 로스터 상태를 `complete`로 바꾼다.

중요:

- 한 번에 캐릭터 한 명만 작업한다.
- `needs-redesign` 캐릭터는 기존 산출물을 `archive/v{기존 버전}`에 보존한 뒤 새 버전으로 제작하고, QA 통과 후에만 manifest가 새 버전을 가리키게 한다.
- 바이블의 `silhouette`, `signature`, `face`, `motion`, `avoid`를 기본 이미지와 모든 모션에 유지한다.
- 바이블에 `colorPlan`이 있으면 머리·상체·하체 배치를 그대로 적용하며 개인 강조색이 세력색보다 넓어지지 않게 한다.
- 몸체는 48×64 안팎의 논리 픽셀 격자, 머리 비율 42~48%, 8~16색으로 제한한다. 미세 장식·그라데이션·긴 천자락을 추가하지 않는다.
- 특정 삼국지 게임·애니메이션·일러스트의 캐릭터 디자인을 복제하지 않는다.
- 대형 5행 × 4열 시트를 최종 분리 원본으로 사용하지 않는다.
- 다른 포즈 조각이 한 픽셀이라도 섞이면 완료가 아니다.
- 생성 이미지가 채팅에 보이는 것으로 완료 처리하지 않는다. 프로젝트 경로에 저장해야 한다.
- 이미지 생성 도구를 사용할 수 없다면 플레이스홀더를 만들지 말고 `error`로 종료한다.

최종 응답은 `config/sprite-agent/report.schema.json` 형식에 맞춘다.
